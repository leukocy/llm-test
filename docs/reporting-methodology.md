# 报告与统计口径

报告页面、Markdown、离线 HTML 和统计表使用同一份请求级汇总。
原始 CSV 保留逐条记录，便于复核。

## 性能测试

- **请求数**：结果中实际记录的行数。请与计划请求数核对；
  中断的运行不能仅凭记录行数视为完整。
- **成功率**：控制面逐请求的空错误值视为成功；历史 CSV 另尊重显式
  `success` 字段，与错误状态冲突时拒绝。历史文件同时缺少成功状态及
  错误列时标为未知；成功率分母仅含已知状态请求，未知请求保留在请求总数中。
  95% Wilson 区间用于描述请求结果的
  不确定性；同一运行中相互关联的失败可能使区间偏窄。
- **耗时与速率**：只取成功请求中有限且大于零的测量值；缺失和零值不补为零。
  每项指标展示自身的有效样本数。控制面汇总包含均值、P50/P95/P99、最小/最大值；
  PNG 绘制 P50/P95。TTFT、TPOT 与总耗时用秒，TPS 与输入处理速度用 token/s。
- **观察性结论**：分位数、图形与小样本提示用于描述观测，不是显著性检验，
  也不证明因果关系。不能将逐请求生成速度等同于系统总吞吐。
- **口径兼容**：同一报告如包含多个 `metric_contract_version`，拒绝合并统计；
  未版本化的历史数据标注为 `legacy-unversioned`。
  令牌计数方法不同会单独提示。
- **控制面报告完整性**：API、HTML 与控制台都显示计划请求数和实际落库数。
  控制任务、测量记录、请求数量与当前指标契约全部通过核验后，才显示
  “单次运行完整性核验通过”；未完成、取消、失败、遗失样本和历史无版本结果
  保留诊断统计，并明确显示原因。跨运行仍需核对配置与环境，原始 CSV
  逐行导出口径版本。
- **历史 CSV 来源**：报告保存原文件和可读取元数据的 SHA-256，明确执行条件、
  计划请求数与预热未经控制队列核验。哈希只识别内容，不证明测量有效。
  从文件重算不产生新测量任务；混用指标契约或超出读取上限时拒绝统计。
- **暂停与执行策略**：控制台、JSON、Markdown、HTML 及测量配置记录暂停次数、
  累计时长和批次并行上限/失败策略。暂停只在已完成的请求组之间生效，
  不计入单请求耗时或连续负载单元的吞吐分母；它可能改变缓存、硬件温度和
  资源监控窗口。并行上限是调度策略，不等于实际重叠数。允许并行的批次
  可能共享服务容量；比较时须核对任务起止时间和其他负载。完整性核验通过
  不代表这些结果与无暂停、串行运行自动可比。

## 质量评测与批量对比

- **质量准确率**：从 `correct_samples / total_samples` 重算；展示数据集
  各自的样本量和 Wilson 区间。固定题库的区间只有在题目可近似看作独立样本时
  才有抽样解释。不同数据集不合成为一个“能力分数”。
- **质量性能**：有逐题测量时展示成功样本的 TTFT P50/P95 与 TPS P50/P10，
  并列出各自有效样本数；只有聚合数据时保留原平均值，不虚构分位数。
- **批量对比**：比较请求成功率、失败数和性能分位数；部分失败、完全失败和
  跳过的项目仍出现在对比表，缺失指标留空。历史结果缺少请求级计数时，
  成功率区间显示为空。

## 导出和复核

控制面 HTML 报告含独立样式和统计表，可离线打开并打印；图形另提供 PNG，
不依赖外部图表 CDN。标题、表格与来源文字做 HTML 转义。CSV/Excel 下载会把
可能被表格软件执行的公式样式文本加上前导单引号。历史 CSV 安全导出保留原列，
隐去凭证字段，原始存储字节不变；与原文件的内容哈希可能不同。
需要逐字核对原始模型输出时，应使用原始结果数据而非安全导出。
